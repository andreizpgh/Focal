The first public alpha of Focal: offline voice notes for Android.

**Download `Focal.apk` below and open it on your phone.** Android 8.0+ and ARM64
are required. If prompted, allow your browser to install apps. No ZIP archive,
GitHub sign-in, or separate model download is needed.

- Record in the background, with pause and finish controls in the notification.
- Transcribe locally with the bundled multilingual Whisper model.
- Review uncertain passages, listen to the audio, and edit the text.
- Copy or share the complete transcript.
- No account, analytics, or Internet permission.

For Russian, choose **Settings → Speech language → Русский** before recording.
The interface and default speech language are English.

This is the exact development-signed APK from the successful
[Android build](https://github.com/andreizpgh/Focal/actions/runs/41421916015),
published without rebuilding or changing its signature. That build passed nine
core tests and eight Android tests, including real speech recognition and
recording after task dismissal. If you already installed that artifact, you
already have this version.

This alpha still needs real-phone measurements of Russian accuracy, long
recordings, battery use, and heat. Export important transcripts while testing.
